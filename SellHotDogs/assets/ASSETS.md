# Sell Hot Dogs: 3D assets

All 22 models are **original, procedurally generated by `tools/blender/build_assets.py`, no third-party content** (no downloaded models, textures, fonts or scans). Colours are plain Principled BSDF materials, also baked into a `Col` vertex-colour attribute so a single MeshPart shows the right colours in Roblox. No image textures are used.

## Rebuilding

From `SellHotDogs/` (needs `pip install bpy==5.0.1 pillow`, Python 3.11):

```
python3 tools/blender/build_assets.py                    # all assets, ~80 s on 4 CPU cores
python3 tools/blender/build_assets.py --only HotDog,Bun  # some assets
python3 tools/blender/build_assets.py --samples 32       # nicer previews
python3 tools/blender/build_assets.py --no-render        # geometry + exports only
```

Each run writes `assets/blender/<Name>.blend`, `assets/exports/<Name>.fbx`, `.obj` + `.mtl`, `assets/renders/<Name>.png`, updates `assets/exports/manifest.json` (size, triangles, materials) and redraws `assets/renders/contact_sheet.png`. Sizes are in studs (1 Blender unit = 1 stud), listed as X width × Y depth × Z height in Blender. Every model is one mesh, centred on X/Y with its lowest point at Z = 0. The front faces Blender -Y.

## Importing into Roblox

The shipped place currently uses **native-part stand-ins** for these models. Uploading meshes needs Carter's Roblox account, so this step is his:

1. In Studio, open **Avatar → Import 3D** (3D Importer). Or use **Asset Manager → Bulk Import** for all FBX files in `assets/exports/`.
2. In the importer, keep the vertex colours on. Each FBX imports as one MeshPart.
3. Set the MeshPart `Size` to the manifest size. Roblox is Y-up, so the manifest's `[X, Y, Z]` becomes Roblox `Size = (X, Z, Y)`: width, height, depth. Set `Anchored = true`. Use `CanCollide`/`CollisionFidelity = Box` for props.
4. Rename it to `<Name>` and put it in `ReplicatedStorage/Assets/<Name>`. The game code clones assets from there instead of the stand-ins.
5. Glow parts (emission) don't carry over through the FBX. Where you want glow (portal, staircase, void hot dog), add a `PointLight` or set a `Neon` material on a copy.

## Audio

| File | Use | Provenance |
|---|---|---|
| `assets/audio/click.wav` | CLICK / button press | Original, synthesised by `tools/audio/gen_sfx.py` (pure Python sine/square/noise; no samples) |
| `assets/audio/cash.wav` | cash pop / deal paid | same |
| `assets/audio/build.wav` | something got built | same |
| `assets/audio/error.wav` | rejected request | same |
| `assets/audio/phone.wav` | incoming phone offer | same |
| `assets/audio/cheer.wav` | DogDash cheer | same |

The place currently plays Roblox's engine-bundled client sounds (`rbxasset://sounds/clickfast.wav`, `electronicpingshort.wav`, `swoosh.wav`, `button.wav`), which ship with every Roblox client, so it makes sound without uploads. To use the originals, upload the WAVs on Carter's account and put their `rbxassetid://` IDs in `SOUNDS` in `src/client/Controllers/Effects.luau`. The engine sound paths were not verified in Studio from this environment.

## Icons

UI icons are Unicode emoji rendered by Roblox's text engine (no image assets). No third-party icon packs are used.
