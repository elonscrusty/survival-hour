# Egg Farm asset manifest

All files listed here are **original works generated by the scripts in this repository** (procedural Blender modelling, Pillow vector drawing and numpy synthesis). No third-party models, textures, fonts, images, samples or recordings were used, and nothing was imported from other projects.

**Not uploaded.** None of these assets have been uploaded to Roblox (no Asset Manager / Open Cloud step has been done). The game currently builds its models from native Parts and draws its icons natively; whether and when to upload these is the owner's decision.

Total size of `assets/`: 6.4 MB (plus 2.5 MB of previews in `docs/renders/`).

## Regenerating

| Command | Produces |
|---|---|
| `python3 blender/build.py [--only Name\|Category] [--no-render]` | FBX + OBJ exports, `.blend` scenes, preview renders, `assets/export/manifest.json` |
| `python3 blender/verify.py` | Re-imports every FBX in a fresh scene; checks triangles, origin, size, OBJ twin, facing |
| `python3 assets/ui/make_icons.py` | `assets/ui/icons/*.png`, `assets/ui/icons_sheet.png` |
| `python3 assets/audio/make_audio.py` | `assets/audio/*.wav` |
| `python3 blender/make_manifest.py` | this file |

Model scripts: `blender/lib.py` (primitives, materials, export conventions), `blender/assets_living.py`, `blender/assets_buildings.py`, `blender/assets_vehicles.py`, `blender/assets_props.py`.

## 3D models

Conventions: one mesh per file, flat shaded, one material per flat colour (`EF_<Colour>`, no textures, no UVs needed), origin at the base centre, authored in metres with 1 stud = 0.28 m. Exported with `axis_forward='-Z', axis_up='Y'`; the model's front faces **-Z** (Roblox LookVector), checked by `verify.py`. Sizes below are W x H x D in studs; triangle budget 10,000 per mesh (Roblox limit 20,000).

Each model has `assets/export/<Name>.fbx`, `assets/export/obj/<Name>.obj` (+ `.mtl`) and a preview `docs/renders/<Name>.png` (320x320). Editable scenes: `assets/blend/<Category>.blend`.

## Upload notes (not done)

- Meshes: Studio **Asset Manager -> Bulk Import** or the **3D Importer** (File -> Import 3D) with the `.fbx` files; or Open Cloud `assets` API with an API key that has asset write access. Keep the import scale at the file's metres (1 stud = 0.28 m) so sizes match the table.
- Colours come from the materials; on import choose to keep vertex/material colours or recolour the MeshPart in game (egg variants have two materials: shell and decoration).
- Icons: upload as Decals/Images, then reference the `rbxassetid://` in the UI.
- Audio: upload WAVs via Asset Manager or Open Cloud (audio uploads need a verified account).
- After uploading, record the asset ids in game data; delete any Open Cloud key used.
