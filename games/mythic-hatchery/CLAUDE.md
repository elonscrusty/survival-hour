# Mythic Hatchery: notes for Claude

A second Roblox game (Rojo + Luau) in this repo: hatch, raise, fuse, ride and race mythical creatures
(formerly "Pet Expedition"; some systems still use pet-era names). The root CLAUDE.md working style applies
(caveman lite replies, short summaries, owner plays on a phone, Fable model for every helper).
Survival Hour rules about locked match numbers do not apply here. Ask the owner before design changes.

- Start with `docs/STATUS.md`; contracts in `docs/CONTRACTS.md`; design in `docs/GDD.md`; art direction in `reference/`.
- Checks: `bash tools/check.sh` (type check with zero diagnostics, unit tests, Rojo build). `--quick` skips the build.
  Selene/StyLua configs exist (`selene.toml`, `stylua.toml`); binaries in /tmp/sh-tools/{selene,stylua}.
- Unit tests: `tests/*.spec.luau`, registered in `tests/run.luau`. Pure rules live in `src/shared/Logic/` (no Roblox types).
- Content is data: `src/shared/{Species,Elements,Eggs,Potions,Cosmetics,Areas}.luau`.
- Models are built from primitives at runtime from `src/shared/Models/ModelData.luau`, generated by
  `python3 models/gen_models.py`. Previews: `python3 models/render.py` (needs `SH_WITH_BPY=1 bash ../../tools/setup_env.sh`) → `renders/`.
- Robux: passes and products in `src/shared/Products.luau` (Id 0 until created). Gem eggs and potions are bought
  with gems. Odds always shown; respect PolicyService (paid random items, paid item trading).
- Commit `build/MythicHatchery.rbxlx` once at the end of a session.
