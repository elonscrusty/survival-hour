# Pet Expedition: notes for Claude

A second Roblox game (Rojo + Luau) in this repo: collect, hatch and send pets on expeditions.
The root CLAUDE.md working style applies (caveman lite replies, short summaries, owner plays on a phone).
Survival Hour rules about locked match numbers do not apply here.

- Start with `docs/STATUS.md`; system contracts in `docs/CONTRACTS.md`; design in `docs/GDD.md`.
- Checks: `bash tools/check.sh` (type check with zero diagnostics allowed, unit tests, Rojo build). `--quick` skips the build.
- Unit tests: `tests/*.spec.luau`, registered in `tests/run.luau`. Pure rules live in `src/shared/Logic/` (no Roblox types).
- Models are built from primitives at runtime from `src/shared/Models/ModelData.luau`, generated by
  `python3 models/gen_models.py`. Previews: `python3 models/render.py` (needs `SH_WITH_BPY=1 bash ../../tools/setup_env.sh`) → `renders/`.
- Robux: passes and products in `src/shared/Products.luau` (Id 0 until the owner creates them). Odds always shown;
  respect PolicyService (paid random items, paid item trading).
- Commit `build/PetExpedition.rbxlx` once at the end of a session.
